# Skim

A calm web browser for the Mac, by MilkStraw AI.

## Download

- [Skim for Apple chip Macs (M1 and newer)](https://github.com/JJhazy/skim-browser/releases/latest/download/Skim.dmg)
- [Skim for Intel Macs](https://github.com/JJhazy/skim-browser/releases/latest/download/Skim-Intel.dmg)

Skim needs macOS 14 or later. Once installed, it keeps itself up to date.

### The first time you open it

Your Mac says it can't check Skim for malicious software, because Skim isn't registered with Apple yet. Click Done, then open System Settings > Privacy & Security, scroll down to the message about Skim and click "Open Anyway". You only do this once.

This repository holds only Skim's finished releases.
